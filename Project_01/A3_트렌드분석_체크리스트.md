### 4. GitHub 저장소

## Ⅱ. 기능 요구사항 (모두 충족해야 함)

### 1. 분석 주제 및 데이터 선정
- [ ] **[필수]** 관심 있는 시계열 데이터 **1개** 선정 (예: 주가·암호화폐, 기온·날씨, 판매량, 환율, 조회수)
- [ ] **[필수]** 데이터 포인트 **100개 이상**
- [ ] **[필수]** 데이터 **출처** 명시 (예: 공공데이터포털, Kaggle, Yahoo Finance)
- [ ] **[필수]** 데이터 **기간** 명시 (예: 2023-01-01 ~ 2024-12-31)

### 2. 분석 질문 설정
- [ ] **[필수]** 데이터로 답하고 싶은 질문 **3개 이상** 정의
- [ ] 질문 유형 섞기 가능: "그래프로 바로 확인되는 것" + "추가 해석이 필요한 것"

### 3. 데이터 정제 및 시계열 분석
- [ ] **[필수]** 데이터 기본 정보 확인
  - [ ] 기간 (시작일~종료일)
  - [ ] 컬럼 (어떤 항목들이 있는지)
  - [ ] 결측치 여부 (비어 있는 값)
- [ ] **[필수]** 결측치·이상치가 있으면 **기준을 정해** 처리 (처리 기준을 리포트에 기록)
- [ ] **[필수]** 시계열 분석 기법 **2가지 이상** 적용
  - 후보: 이동평균 / 변화율 / 구간별 통계 / 변동성·표준편차 / 월별·요일별 집계

### 4. 시각화
- [ ] **[필수]** 시각화 2개 이상 리포트에 포함
- [ ] **[권장]** 추가 1개 이상 (총 3개 이상)
- [ ] 시각화 점검 (PDF 가이드)
  - [ ] **축**: 날짜 정렬이 맞는지, 빠진 구간은 없는지
  - [ ] **스케일**: 값 범위가 커서 변화가 평평하게 보이지 않는지
  - [ ] **집계 단위**: 일/주/월 중 왜 그 단위를 골랐는지 리포트에 한 줄 이상 근거 기록

### 5. 인사이트 도출 및 리포트 작성
- [ ] **[필수]** 인사이트 **3개 이상**
- [ ] **[필수]** 각 인사이트에 "그래프에서 확인한 관찰(수치/근거)" 포함
- [ ] 인사이트 작성 형식 (PDF 예시)
  - [ ] 관찰(Fact): 그래프에서 확인한 수치·구간
  - [ ] 원인(Why): 가능한 원인 가설 1~2개 (근거·반례 포함 가능)
  - [ ] 행동(Action): 의사결정·추가 분석·다음 실험 제안
- [ ] **[필수]** REPORT.md에 주제·질문·데이터 설명·시각화·인사이트·결론/한계점 정리

- [ ] **[선택]** 제출 방식 **택 1**
  - [ ] (1) 배포 URL 1개
  - [ ] (2) 로컬 실행 화면 녹화(또는 시연 영상) + 실행 방법 문서
  - [ ] (3) 대시보드 스크린샷 세트 + 필터·기간 변경 시나리오 설명

### 2. 시계열 심화 옵션 (분해/예측)
- [ ] **[선택]** 아래 중 **1개 이상** 수행
  - [ ] (A) 시계열 분해: 추세·계절성을 분리해 해석
  - [ ] (B) 간단 예측: 베이스라인 방식으로 짧은 구간 예측 (정확도보다 "가정/한계" 설명에 집중)
- [ ] **[선택]** 결과를 시각화 **1개 이상**으로 남기기

## 2. 프로젝트 개요

**무엇을 했나**
네이버에서 "통영 여행"을 검색한 양이 **매주 어떻게 오르내렸는지** 5년치를 받아서,
거제·남해와 비교하며 **반복되는 패턴**과 **달라진 흐름**을 찾았습니다.

**왜 이 주제인가**
저는 통영의 호텔 마케팅을 하고 있습니다. "손님이 언제 여행을 알아보기 시작하는가"를 알면
광고를 언제 걸지 정할 수 있습니다. 검색은 실제 방문보다 **먼저** 일어나니까요.

**던진 질문 4개**

| # | 질문 | 쉽게 말하면 |
|---|---|---|
| Q1 | 1년 중 언제 가장 높고 낮은가? | 성수기·비수기는 언제? |
| Q2 | 5년 동안 흐름은 어떤가? | 인기가 오르는 중? 내리는 중? |
| Q3 | 갑자기 튄 주는 언제인가? | 무슨 일이 있었나? |
| Q4 | 겨울에 얼마나 떨어지나? | 비수기가 얼마나 심한가? |

## 3. 데이터 분석 용어 풀이

> 데이터 분석을 처음 보는 사람에게 설명한다면 이렇게 말하겠습니다.

### 먼저 — 이 숫자는 "검색 횟수"가 아닙니다

가장 많이 오해하는 지점입니다.

| | 실제 검색 횟수 | 이번 데이터(상대 지수) |
|---|---|---|
| 뜻 | 1,234번 검색됨 | **가장 많았던 주를 100으로** 놓고 나머지를 비율로 |
| 예시 | — | 50 = 최고점의 절반 |
| 비유 | 시험 원점수 | **반 1등을 100점으로 환산한 점수** |

그래서 "통영 검색이 25번"이 아니라 **"최고점 대비 25% 수준"**이라고 읽어야 합니다.
세 지역을 **한 번에** 받아야 같은 기준(100)으로 비교할 수 있어서, 한 번의 요청으로 받았습니다.

---

### 핵심 개념 4가지

**① 시계열 (time series)**
**시간 순서대로 쌓인 데이터**입니다. 매일 재는 키, 매주 몸무게, 매달 용돈 기록 같은 것.
순서가 의미를 가지기 때문에, 순서를 섞으면 분석이 안 됩니다.

**② 추세 · 계절성 · 노이즈**
하나의 그래프 선은 세 가지가 섞여 있습니다.

| 이름 | 뜻 | 비유 |
|---|---|---|
| 추세 | 몇 달~몇 년에 걸친 **큰 흐름** | 키가 해마다 크는 것 |
| 계절성 | **매년 같은 때** 반복되는 오르내림 | 여름마다 아이스크림이 잘 팔리는 것 |
| 노이즈 | 그 주에만 생긴 **우연한 흔들림** | 어느 날 갑자기 비가 와서 덜 팔린 것 |

**③ 결측치와 이상치**
- **결측치** = 빠진 값. 출석부에 빈칸이 있는 것. → 이번 데이터엔 **0개**였습니다.
- **이상치** = 튀는 값. 반 평균 60점인데 혼자 100점인 것. → **오류인지, 진짜인지** 먼저 따져야 합니다.

**④ 관찰과 해석**

| 관찰 (사실) | 해석 (가설) |
|---|---|
| 그래프에서 **눈으로 확인한 것** | 그 이유에 대한 **내 추측** |
| "7월에 가장 높다" | "여름휴가 때문일 것이다" |
| 누가 봐도 같음 | 틀릴 수 있음 |

과제가 가장 강조한 부분입니다. **둘을 섞어 쓰면 추측이 사실처럼 보입니다.**

---

### 사용한 분석 기법 4가지

| 기법 | 한 줄로 | 어떤 질문에 답하나 |
|---|---|---|
| **이동평균** | 앞뒤 몇 주를 묶어 **평균으로 부드럽게** | Q2 흐름 |
| **월별 집계** | 5년치를 **달별로 모아 평균** | Q1 성수기·비수기 |
| **변화율** | 지난주보다 **몇 % 올랐나** | Q3 급등한 주 |
| **구간별 통계** | 여름·겨울을 **따로 모아 비교** | Q4 비수기 격차 |

**이동평균을 쉽게 말하면**
시험 점수가 70 → 95 → 65 → 80으로 들쭉날쭉하면 실력이 오르는지 모릅니다.
**최근 3번 평균**을 내면 들쭉날쭉이 줄고 흐름이 보입니다. 이번엔 **12주(약 3개월)** 평균을 썼습니다.

---

### 그 밖에 알아두면 좋은 것

| 용어 | 뜻 |
|---|---|
| API | 프로그램끼리 데이터를 **주고받는 창구**. 네이버에 "이 조건으로 데이터 줘" 하고 요청 |
| API 키 | 창구에서 쓰는 **내 이용증**. 남에게 보이면 안 됨 → `.env` 파일에 따로 보관, GitHub엔 안 올림 |
| IQR | 이상치를 찾는 기준. 값을 줄 세웠을 때 **가운데 절반의 폭**을 기준으로 너무 멀리 떨어진 값을 찾음 |
| 노트북 (.ipynb) | 코드 바로 아래 **결과 표·그래프가 같이 보이는** 파일 |
| 대시보드 | 버튼·슬라이더로 **조건을 바꿔 가며 보는 화면** |

## 4. 작업 도구 및 내용

**도구**

| 역할 | 도구 | 비고 |
|---|---|---|
| 편집기 | Cursor | |
| 언어 | Python 3.14.7 | pandas(표 계산), matplotlib(그래프) |
| 데이터 | 네이버 데이터랩 API | NAVER API HUB 키 |
| 대시보드 | Streamlit | 파이썬만으로 웹 화면 |
| 버전 관리 | Git + GitHub | 커밋 12개 |

**핵심 설계 판단 세 가지**

**① 튀는 값을 지우지 않고 표시만 했습니다**

통계 기준(IQR)으로 이상치를 찾으니 39개가 나왔습니다. 그런데 **전부 4~8월**에 몰려 있었습니다.
매년 같은 계절에 반복된다면 오류가 아니라 **진짜 여름 휴가 수요**입니다.
지웠다면 "성수기가 언제냐"는 질문의 답 자체가 사라졌을 겁니다.

**② "비수기가 좋아졌다"고 쓰려다 멈췄습니다**

겨울÷여름 비율이 5년간 올랐습니다(통영 0.55 → 0.70). 처음엔 "비수기가 좋아졌다"로 읽었습니다.
그런데 실제 숫자를 보니 **겨울은 조금 오르고(17.9 → 20.0), 여름이 많이 빠졌습니다(32.5 → 28.4).**
비율은 분자가 올라도, 분모가 내려가도 오릅니다. **비율만 보면 속을 수 있다**는 걸 확인한 판단입니다.

**③ 근거가 부족한 인사이트는 뺐습니다**

통영 검색이 **77% 급등한 주**가 있어서 찾아보니, 대선 임시공휴일로 연휴가 생긴 직전 주였습니다.
추석 연휴, 장마 종료 직후도 비슷했습니다. 그럴듯하지만 **"같은 때 일어났다"와 "그것 때문이다"는 다릅니다.**
연휴인데 안 튄 주가 있는지 확인하지 않았기 때문에, 인사이트에서 빼고 관찰로만 남겼습니다.

## 5. 과제 체크리스트 및 수행 여부

**필수 전부 완료. 보너스 1·2 전부 완료.**

| 구분 | 결과 | 한 줄 근거 |
|---|:--:|---|
| 데이터 100개 이상 | **262주 × 3** | 네이버 데이터랩, 2021~2025 |
| 분석 질문 3개 이상 | **4개** | Q1~Q4 |
| 결측치·이상치 처리 | **완료** | 결측 0건 / 이상치 39건은 표시만, 이유 기록 |
| 시계열 기법 2개 이상 | **4개** | 이동평균·월별 집계·변화율·구간별 통계 |
| 시각화 2개 이상 (권장 3개) | **5개** | `images/01~05` |
| 인사이트 3개 이상 | **3개** | 관찰·해석·행동으로 나눠 작성 |
| 재현성 | **완료** | `requirements.txt`, 실행 방법, 새 환경 재실행 확인 |
| AI 사용 로그 | **완료** | 작업·이유·검증 방법 7가지 |
| 보너스 1 대시보드 | **완료** | Streamlit, 스크린샷 4장 + 시나리오 |
| 보너스 2 시계열 분해 | **완료** | 추세·계절성·나머지로 분해, 검산 오차 0 |

**보너스에서 일부러 한 선택 — 분해를 라이브러리 없이 직접 계산**

`statsmodels`라는 도구를 쓰면 한 줄이면 됩니다. 그런데 그 안에서 무슨 일이 일어나는지 설명할 수 없습니다.
그래서 **이미 만든 이동평균을 추세로 쓰고, 뺄셈과 평균만으로** 나눴습니다.
세 조각을 다시 더했을 때 원본과 **차이가 0**인 것까지 확인했습니다.

## 6. 배운 점 3가지

### ① 그래프를 그리는 것보다 읽는 게 훨씬 어렵습니다

과제 첫 문장이 이랬습니다. "그래프를 그리는 건 어렵지 않다. 어려운 건 해석하는 일이다."
해 보니 맞았습니다. 그래프 5장은 금방 나왔습니다.

어려웠던 건 **"그래서 이게 무슨 뜻이냐"**였습니다.
비율이 올랐으니 좋아진 줄 알았는데 여름이 빠진 거였고,
급등한 주에 연휴가 있었으니 연휴 때문인 줄 알았는데 증명은 못 했습니다.

**숫자 하나를 볼 때도 "그 숫자는 어떻게 만들어졌지?"를 먼저 묻게 됐습니다.**

### ② 오류 메시지가 답을 알려 줍니다

데이터를 처음 받을 때 `401` 오류가 났습니다. 키를 잘못 넣은 줄 알았습니다.
메시지를 다시 읽으니 **"이 API가 이 Application에서 활성화되어 있지 않다"**고 써 있었습니다.
키는 맞았고, 그 키에 **검색어트렌드 사용 권한을 연결 안 한 것**이었습니다.

노트북 실행이 안 될 때도 마찬가지였습니다. `Python 3.14.7`이 두 개라 헷갈렸는데,
**버전 숫자가 아니라 경로(`.venv`)**를 봐야 구분이 됐습니다.

**당황해서 이것저것 누르기 전에, 메시지를 끝까지 읽는 게 가장 빨랐습니다.**

### ③ 실무에 바로 쓸 수 있는 결과가 나왔습니다

통영 호텔 마케팅을 하면서 "비수기 판촉은 12월부터"라고 막연히 생각했습니다.
데이터를 보니 **관심은 11월에 이미 바닥**이었습니다. 12월에 시작하면 늦습니다.

그리고 2025년에 세 지역이 **함께** 떨어진 걸 보고,
"우리 호텔만의 문제가 아니라 남해안 전체의 흐름"이라는 걸 숫자로 설명할 수 있게 됐습니다.

**감으로 하던 판단에 근거가 생겼습니다.** 이번 미션에서 가장 크게 얻은 것입니다.
